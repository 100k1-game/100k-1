# 100 к 1 — Семейная викторина

Онлайн-игра на GitHub Pages. Работает без сервера — синхронизация через P2P (PeerJS).

## Деплой на GitHub Pages

1. Загрузите проект на GitHub
2. Settings → Pages → Source: **GitHub Actions**
3. Push в `main` — сайт опубликуется автоматически

Адрес: `https://ваш-логин.github.io/название-репо/`

## Ключи лобби

Смотрите файл **KEYS.md** — там 5 ключей для 5 одновременных игр.

## Как играть

1. **Ведущий** → Панель ведущего → ключ или лобби 1–5
2. Копирует ссылку для табло
3. Настраивает команды → **«Начать игру»**
4. **Зрители** открывают ссылку → экран ожидания → игра
